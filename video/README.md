# Поиск объектов в видео

Программа проходит по кадрам видео, ищет объекты из набора COCO, рисует рамки и названия классов и сохраняет файл с результатом. Используется Faster R-CNN с компактной основой MobileNetV3 из TorchVision.

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe video\app.py "путь\к\видео.mp4"
```

Выходной файл будет сохранён рядом с исходным под именем `имя_proccessed.mp4`. Путь можно задать явно:

```powershell
.\.venv\Scripts\python.exe video\app.py "путь\к\видео.mp4" --output "результат.mp4"
```

По умолчанию программа сама выбирает CUDA, если она доступна, иначе использует CPU.
