# Распознавание речи

Программа принимает аудиозапись и выводит её текстовую расшифровку. Используется мультиязычная модель `openai/whisper-tiny` через Transformers и PyTorch. Перед подачей в модель звук приводится к моно и частоте 16 кГц.

Поддерживаются WAV, FLAC и OGG длительностью до 30 секунд. 

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe audio\app.py "путь\к\записи.wav"
```

Чтобы сохранить расшифровку в тесктовый файл:

```powershell
.\.venv\Scripts\python.exe audio\app.py "путь\к\записи.wav" --output "расшифровка.txt"
```
