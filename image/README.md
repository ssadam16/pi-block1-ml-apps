# Классификация изображений

Программа принимает изображение и печатает пять наиболее вероятных классов ImageNet с оценками модели. Для классификации используется MobileNetV2 с готовыми весами ImageNet из TorchVision.

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe image\app.py "путь\к\фотографии.jpg"
```

Поддерживаются обычные форматы изображений, которые открывает Pillow. При первом запуске PyTorch скачает веса MobileNetV2.
