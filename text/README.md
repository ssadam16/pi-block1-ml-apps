# Анализ тональности текста

Программа принимает короткий русский текст и возвращает один из трёх классов: положительный, нейтральный или отрицательный. 

Используется `cointegrated/rubert-tiny-sentiment-balanced` через Hugging Face Transformers и PyTorch.

Запуск из корня проекта:

```powerShell
.\.venv\Scripts\python.exe text\app.py --text "Фильм мне очень понравился"
```

В ответе программа печатает предсказанный класс и вероятности для трёх классов.
